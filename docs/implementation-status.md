# Fashion Archive 実装・確認状況

更新日: 2026-10-21

## 実装済み

- React、TypeScript、ViteによるPWA基盤
- IndexedDB（Dexie）へのアイテム・写真・カテゴリー・設定保存
- アイテム登録・編集・詳細・ゴミ箱
- 写真0～3枚、WebP圧縮、サムネイル、順番変更、表紙設定
- 一覧、検索、複合絞り込み、並べ替え、お気に入り
- 一覧へ戻ったときのスクロール位置復元
- 詳細写真のボタン操作・左右スワイプ・全画面表示
- 購入金額・件数の各種集計
- カテゴリー追加・名称変更・並べ替え
- 30日以上経過したゴミ箱項目の整理案内
- ZIP完全バックアップ、検査、置き換え復元
- CSV出力
- 保存容量、最終バックアップ日時、オンライン状態の表示
- オフラインキャッシュ、更新通知、iPhone用ホーム画面アイコン
- GitHub Pages自動テスト・ビルド・公開ワークフロー

- `pnpm install --frozen-lockfile`: 成功
- `pnpm test`: 3ファイル、7テスト成功

## 公開前に必要になる利用者操作

1. 使用するGitHubアカウントを確認する
2. GitHub上に空のリポジトリを作成する
3. GitHub Pagesの公開元を「GitHub Actions」に設定する
4. 公開URLをiPhoneのSafariで開く

実施時は、画面ごとに操作手順を案内する。
