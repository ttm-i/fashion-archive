# Fashion Archive 改修ロードマップ

更新日: 2026-10-21

## 基本方針

- iPhone専用、オフライン優先、端末内保存を維持する
- 機能追加後も写真中心の簡潔なUIを保つ
- 各段階を「実装・自動テスト・公開・iPhone実機確認」まで完了してから次へ進む
- データ形式の更新では既存データと旧バックアップの互換性を維持する

## 改修順序

1. 安全機能とデータ拡張基盤
   - 入力途中の自動保存・再開
   - バックアップ推奨案内
   - IndexedDBの安全な移行と旧バックアップ互換
2. 一覧・検索・詳細画面
   - ブランド、カテゴリー、カラー、購入期間などの複合絞り込み
   - 検索、絞り込み、並べ順の再起動後復元と一括クリア
   - 一覧価格表示の設定
   - 詳細画面の前後移動とスワイプ
3. ほしいもの
   - 購入候補の記録
   - 購入済みアイテムへの移動
4. 素材・混率
   - 素材名のみ、または合計100%の混率
5. 統計強化
   - 集計期間、値引き、ブランド、カテゴリー、カラー、購入方法、購入先
   - 内訳からコレクション絞り込みへの移動
6. 採寸記録
   - 自由入力のサイズ欄は継続
   - アウター、トップス、ボトムスの任意寸法
7. 写真の表示位置
   - 元画像を変更せず、正方形一覧での表示中心だけを調整

## 対象外

- タグ、アイテム複製
- 採寸比較、寸法並べ替え、ポジショニングマップ、サイズガイド
- 写真の回転・実データの切り抜き
- PC同期、自動クラウドバックアップ、バックグラウンド通知
